# Zentrale VA & IF

Gemeinsamer Rahmen für die Arbeit mit Claude Code für VIOLIN ASSETS und die INSTRUMENTUM Foundation.

- `CLAUDE.md`: Anleitung, die Claude zu Beginn jeder Session liest (wer ist wer, feste Regeln, wo was liegt, Arbeitsweise)
- `.claude/settings.json`: Freigaben für Claude Code (Notion-Aktionen ohne Rückfrage, Löschen weiterhin mit Rückfrage)

Die ausführliche Dokumentation liegt in Notion in der „VA & IF Zentrale“. Alle Aufgaben stehen in Notion unter „ToDos IF / VA“.

Dieses Repository enthält keine vertraulichen Inhalte und keine Gestaltungsregeln einer Organisation. Die Design Systems liegen in den Dokumente-Repositories von VA und IF.
